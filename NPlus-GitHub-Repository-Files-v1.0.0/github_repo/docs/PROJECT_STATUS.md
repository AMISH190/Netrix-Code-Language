# N+ v1.0 — Project Status

N+ is the programming language project of **Netrix Development**.

## v1.0 focus
- `.npl` source files
- `*` and `!` statement terminators
- variables and assignment
- expressions and comparisons
- functions
- conditionals
- REPL
- friendly CLI output
- readable compiler errors
- starter VS Code extension
- official website starter

8. N+ AI
