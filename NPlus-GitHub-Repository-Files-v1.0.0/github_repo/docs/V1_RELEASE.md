# N+ v1.0 Release Notes

N+ v1.0 is the first public foundation release from **Netrix Development**.

### Included

- `.npl` source files
- `*` and `!` statement terminators
- variables and assignment
- arithmetic and comparisons
- boolean operators
- functions
- conditionals
- string interpolation
- REPL
- friendly terminal presentation
- NPL diagnostic codes
- VS Code syntax highlighting and snippets
- N+ file icon theme
- official website starter
- CI workflow

### Important scope

N+ v1.0 is a language-core publication, not a promise that every planned Web, Discord, Minecraft, AI or native backend feature is complete. Those components are the next ecosystem milestones.
